# 给 Cursor 的提示（窗口标题：C2.5 | 玉兔小屋续作）

你在接手一份已经做好的「玉兔小屋」无桥版 HTML Demo。请在现有基础上继续，不要另起炉灶。

## 先做这些，然后等待

1. 阅读同目录的 `HANDOFF.md`，再打开 `yutu_house_demo.html` 和 `previews/`。
2. 需要动资源或重建时，再看 `src/`（`template.html`、`build.py`、`mkgeom.py`、`prep.py`、几何和 WebP）。
3. 用简体中文向 Bohao 确认你已理解基线，然后**停止，等待他的下一步指示**。
4. 他还没有指定具体修改。在他说「开始做」或「请做」之前，不要改功能、不要重构、不要扩大范围。

## 必须遵守

- 不要重做这一版；效果展示不做大做全。
- 不要把 Demo 接入微信小程序，不要改 eggbabe 仓库或 PRD，不要 merge，不要上传小程序。
- 这是「一张小屋图 + 角色精灵 + 2D 寻路/遮挡/光照」，不是完整真 3D。不要改成 3D 引擎或大型项目。
- 不确定的内容先问 Bohao，不要自行决定。
- `HANDOFF.md` 第 7 节的已知问题（隔墙偏高、咖啡/厨房到阳光房需绕行、兔偏小、无背面、椅子轻微重叠、未真机验收）只是现状说明，**不是已授权的整改任务**。

## 已有能力（不要丢掉，也不要未请自改）

站立呼吸与眨眼；点击地面寻路并穿门；障碍与前后遮挡；按位置光照染色；拖拽/缩放到 0.45–1.5 并跟随角色。细节以 `HANDOFF.md` 和源文件为准。
