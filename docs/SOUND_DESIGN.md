# SOUND_DESIGN.md — 蛋宝宝（Eggbabe）全场景交互声学与双宠配音规范

## 1. 核心听觉设计原则
- **零循环 BGM，100% 触感微拟音（Micro-Foley）+ 无词软萌小音节**：
  - 平时桌面待机、滚动三屏全景画卷、悬停、普通气泡淡出保持 **100% 安静留白**，拒绝洗脑循环背景音乐。
  - 所有主动交互均提供短促、温润、有真实物理材质感的微拟音与角色小音节，外部音频文件体积 **0 KB**。
- **PlinkFX 合成内核 × 蛋宝宝专属定制融合引擎（[`living-room-dress/sound-engine.js`](../living-room-dress/sound-engine.js)）**：
  - 底层吸收 `maximilianfeix/plinkfx`（MIT）核心算子：Simper 零延迟状态变量滤波（SVF）、PolyBLEP 抗混叠、`modal` 多模态物理打击共鸣（胡桃木、黄铜、玻璃）、三频段 `formant` 咽喉元音滤波、负指数自然冲击衰减与早期木屋反射。
  - 混音与跨端护栏：每个点状音效空闲预渲染 **4 个种子变体（4-Take）** 避免连续重样；内置 `cooldown` 防同帧叠音爆音、4 复音平滑抢占、`-5 dB` 动态压缩限幅，支持首次手势 `navigator.audioSession.type = "playback"`（iOS 16.4+ 静音键兼容）与 `EggbabeNative.haptic` 触感联动。

## 2. 玉兔 (Yutu) vs 锦鲤 (Koi) 双宠声学基因表

| 声学维度 | 🐰 玉兔 (Yutu) — 「干爽蓬松 · 羊毛毡与长耳微风」 | 🐟 锦鲤 (Koi) — 「圆润 Q 弹 · 水珠与幸运气泡」 |
| :--- | :--- | :--- |
| **物理材质隐喻** | 羊毛毡、粗棒针绒线、晒暖棉花团、干燥胡桃木 (`modal [1, 2.32, 4.25, 6.63]`) | Q 弹果冻软胶、清透水珠、圆润鹅卵石、珠光肥皂泡 (`fm` 水滴 + 正弦弯音) |
| **嗓音基频与共振峰** | 中高音区（`430–680 Hz`），柔和三角波 + `YUTU_FMT [350, 1920, 2760]` + 粉红气声 | 中低圆润音区（`300–520 Hz`），纯净正弦波 + `KOI_FMT [470, 930, 2280]` + 向上滑音 |
| **无词拟声小音节** | 短促蓬松的 **「唔～」「啾」「嘿嘿啾」「唔呜…」** | 圆滑连贯的 **「咕噜～」「啵！」「噗噜～♡」「呜噗…」** |
| **桌面小碎步 (`step`)** | 胡桃木 `modal` 低通轻叩 + 羊毛毡粉红噪声轻擦（左右脚微音差） | 圆润水胶微吸附 `Plip-Plop` 上挑正弦 + 极轻水珠泛音 |
| **欢快大跳 (`jump`)** | 轻盈腾空 + **长兔耳扑扇微风** + `740ms` 棉花团蓬松吸震落地 | 水珠弹射跃起 + `740ms` 果冻颤音（`vib [20, 1.8]`）Q 弹落地 |
| **小跳 / 弹跳 (`minihop` / `bounce`)** | 干爽蹬垫「啾噗」 / 低阻尼毛团挤压软回弹「唔噗～」 | 小鱼吐泡「啵噜」 / 软胶水球颤音回弹「duang-啵」 |

## 3. 全场景交互声音矩阵

### 3.1 床头《奶肚黑猫警长发条钟》
- **点击床头闹钟飞入（`clockOpen`）**：毛毡拂风声 + 2 声清脆黄铜擒纵叉迎宾滴答。
- **走针滴答（`clockTick`）**：打开闹钟弹窗期间默认每秒轻柔双拍 `Tick-Tock`；关闭弹窗后按背面「呼噜滴答」拨杆决定是否常驻，开启拨杆时叠加猫呼噜 `brown` 暖低频呼吸包络。
- **正反 180° 翻转（`clockFlip`）**：正翻背为毛毡拂风 + 胡桃木黄铜底盖沉稳落音；背翻正为毛毡拂风 + 清亮表蒙微泛音。
- **背面五角警星纯解压黄铜发条（`#ip-clock-fidget-key`）**：严守零倒计时焦虑红线；支持**轻点拧一格（4 连齿咔哒）**与**按住画圈/滑动连续拧发条**（棘轮音高随拧动速度与张力微升，松手触发止逆爪「叮咔」回弹落锁音并带动黑猫尾巴轻晃）。
- **班次按钮与呼噜拨杆（`clockShift` / `clockLever`）**：胡桃木档位定位声与黄铜机械拨杆扳动声。

### 3.2 投喂与 8 款小零食差异化咀嚼
- **拾取与抛投**：按下卡片触发托盘拾取轻提音（`snackPickup`），点击飞入嘴边触发轻巧抛物线微风声（`snackToss`）。
- **5 类物理材质 × 双宠吃相（`munch(snackId, petId)`）**：
  - `carrot`（脆脆胡萝卜）→ 爽脆生鲜折断声（高通瞬态 + `crunch 3200Hz`）；
  - `dried_fish`（香酥小鱼干）/ `crispy_taiyaki`（香酥鲷鱼烧）→ 薄烤酥皮颗粒碎裂声（鲷鱼烧叠加软糯豆沙尾韵）；
  - `berry_mochi`（草莓大福）→ 低通黏软糯团挤压声；
  - `osmanthus_cake`（桂花蜜糕）/ `osmanthus_pancake`（桂花蜜松饼）→ 温暖粉红噪声绵密气孔轻嚼声；
  - `cream_berry`（奶油小草莓）/ `star_candy`（幸运星星糖）→ 饱满浆果多汁轻咬 / 晶莹硬糖 `modal` 清脆轻碰。
  - **玉兔吃相**：快门牙连啃 4 下 + 满足鼻音叹息「唔～啾♡」；**锦鲤吃相**：圆嘴慢嚼 3 下 + 开心上扬水泡「咕噜啵～」。

### 3.3 洗澡揉搓手速效率联动与冲水收尾
- **手速强度映射（`computeScrubEffort` & `computeBathStepDelta`）**：
  - 玉兔长绒毛慢热曲线：`0–30%` 浸润期 `×0.78`，`30–100%` 绵密发泡期 `×1.28`，实时粉红噪声柔擦流 + 绵密低泡「噗噗」声，满 `100%` 触发温水淋浴 + **噗噜噜长耳抖毛蓬松声**。
  - 锦鲤滑溜鱼身轻快曲线：`0–40%` 快速起泡 `×1.18`，`40–100%` 水润抛光 `×0.96`，实时水润啾啾擦拭流 + 清脆珠光「啵啵」泡，满 `100%` 触发清亮泼水 + **甩尾跃水五声琶音**。

### 3.4 起居室热点与周边微拟音
- **睡眠唤醒（`sleepPat`）**：轻拍被窝蓬松声 + 睡意小哼唧 → 台灯暖咔哒 → 落地角色小跳。
- **高频拟物道具**：桌面原木小立镜玻璃星芒（`mirrorSparkle`）、衣橱试穿织物摩挲（`clothRustle`）、3D 百宝箱木扣开合（`chestToggle`）、多宝格橡木落槽（`woodSlot`）、手帐布搭扣（`bookClasp`）/ 翻页（`pageFlip`）/ 写手帐铅笔沙沙声（`pencilWrite`）、拍立得机械快门（`cameraShutter`）、推门切房（`doorSlide`）及内置轻游艺（`cardFlip` / `cardMatch` / `ovenHit` / `ovenDing` / `breezeChime`）。
