# 蛋宝宝装扮屋 · 原生微信小程序（`wxapp/`）

零框架依赖的原生微信小程序工程，个人主体即可注册并提审上线（无需软件著作权、无需 `<web-view>`），后期支持微信官方主体迁移至企业主体。

## 核心功能
- **双宠切换**：锦鲤 BOON KOI（12 套全身弹性透明装 + 毛绒眼皮滑动眨眼 Shader） & 玉兔 Yutu（8 款头饰/围巾多槽位叠戴）
- **11 套场景背景**：奶油暖屋 + 10 套风格背景实时切换，联动脚底投影色温
- **原生 WebGL 互动**：轻点身体跳跃、轻点头部歪头眨眼、按住揉搓眯眼、6.5 秒静置自动打盹
- **一键存壁纸 + 分享好友**：离线 2D Canvas 合成 `780×1688` 高清手机壁纸保存到系统相册

## 3 分钟导入微信开发者工具

1. 打开 **微信开发者工具** → 选择「导入项目」→ 目录选择本仓库的 `wxapp/` 文件夹。
2. AppID 填你自己的个人小程序 AppID（本地体验也可先用「测试号」）。
3. 确认右上角「详情 → 本地设置」中已勾选 **「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」**（`project.config.json` 已默认关闭校验）。
4. 编译后即可在模拟器与真机预览中直接体验换装、11 套背景切换与壁纸保存！

## 正式提审上线前（仅需改 1 行配置）

1. 将仓库中的 `assets/shared/`、`assets/koi-v2b/work/sets/`、`assets/v2b/work/` 静态图片上传至你自己的已备案 HTTPS 存储（如腾讯云 COS / 阿里云 OSS / 微信云托管）。
2. 打开 `wxapp/config/cdn.js`，把 `CDN_BASE` 替换为你的域名。
3. 在微信公众平台后台「开发管理 → 开发设置 → 服务器域名」中，将该域名添加到 **`downloadFile` 合法域名**（用于壁纸导出与纹理加载）。
4. 类目推荐选择：**工具 → 摄影美化 / 壁纸头像**（个人主体免软著、审核通过率高）。
