# 蛋宝宝牧场（一期）

Vite + TypeScript + Three.js，390×844 竖屏舞台，与玉兔小屋一致的 `#fit` 缩放。

## 在线（默认）

**https://octopusgump.github.io/eggbabe-h5/danbaobao-meadow/site/**

（合并到 `main` 后由 GitHub Actions 自动 `npm run build` 并更新 `site/`。）

## 开发（可选）

```bash
cd danbaobao-meadow
npm install
npm run dev
```

## 一期能力

- 粘土风草场：浮岛、小河、土路、树木、中心方圈羊圈（四角开口）
- 11 只羊：漫步、可拖拽；空白处旋转视角、滚轮缩放
- UI：蛋宝宝牧场品牌；暂停 / 重置；草场羊只计数

二期预告：可控 `rabbit`、60 秒聚拢、星级 = 进圈只数。
