# Prototypes 原型目录

本目录用于存放团队成员独立开发的 H5 / 小程序玩法原型。详细放置、命名与资源规范见 [`docs/PROTOTYPE_CONVENTIONS.md`](../docs/PROTOTYPE_CONVENTIONS.md)。

## 快速上手

1. 从 `main` 拉分支：`proto/<owner>-<feature>`
2. 在本目录下新建文件夹：`prototypes/<owner>-<feature>/`
3. 放入 `index.html`（和/或 `wxapp/`）与 `README.md`
4. 在下方索引表中登记一行，提 PR 合入 `main`
