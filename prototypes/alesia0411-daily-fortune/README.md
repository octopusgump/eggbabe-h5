## 玩法

点击签筒开始摇签，基础时长 3 秒，每次点击增加 0.3 秒，最多 100 次。摇动时有粒子、按压反馈和每 10 次触发的宠物气泡。落签后展开签纸，可保存、分享，并选择解读方向及可选问题进行 AI 解签。

签文库包含 360 条签文，按渐进、舒缓、相知、自信、新意、专注、悦纳、选择、欣喜、生长、坦诚、期待分为 12 类，每类关联 5 张随机配图。菜单可切换兔兔/小鱼及对应印章，或进入固定签文演示路径。抽签结果、配图和伙伴偏好保存在当前浏览器本地。

## 本地启动与 AI 配置

使用 Node.js 22 或更新版本，在本目录执行：

```sh
cp .env.example .env
# 仅在本机 .env 中填写 DEEPSEEK_API_KEY
npm run dev
```

访问 http://127.0.0.1:4181 。Windows PowerShell 可使用 `Copy-Item .env.example .env` 复制配置。此项目运行时无需安装第三方依赖。

真实密钥仅由服务端读取，仓库只提供空白 `.env.example`。用户点击解读确认后，签文编号、方向、可选问题和伙伴类型发送至本地服务，再由服务调用 DeepSeek。

GitHub Pages 只能运行静态玩法，不能执行 Node.js 或直接提供 AI 解签。完整体验需要部署 `server/local.mjs`（以及 shared 和静态资源），使用服务器环境变量配置密钥。若通过 `/prototypes/alesia0411-daily-fortune/` 反向代理，需在代理层剥离该前缀，使前端相对路径的 `api/interpret` 转发到服务端 `/api/interpret`。不要在网页代码中填写 API key。

## 目录与素材

- `js/`：页面流程、摇签反馈、配图、印章、保存与分享。
- `shared/`：签文库、抽取规则和分类图片映射。
- `server/`：DeepSeek 服务端适配及本地静态服务。
- `assets/`：本原型的专属 PNG 素材。保留用户确认的角色、印章、纸张与主题图，不修改全仓共享资源。
- `tests/`：已有逻辑测试；`npm test` 可运行。

上传整理将网站根路径改为相对路径，并将分类图片目录改为英文。图片使用 pngquant --quality=80-95 --speed=3 --strip 压缩；未通过最低质量阈值的图片改用无损 PNG 优化以保留画质，未引入 WebP。原型没有携带真实密钥、运行日志、用户输入记录或本机绝对路径。
