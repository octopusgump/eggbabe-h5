# 蛋宝宝 · 窗边起居室与专属试衣间（单场景原型）

融合 `eggbabe-h5` **v2b WebGL 实时网格换装**（玉兔 + 锦鲤）与 `eggbabe-miniprogram` **破壳后居家生活页（`life-scene`）** 视觉语言的单场景交互原型。

## 核心能力

1. **单场景起居室（`1024 × 576` 纯净空底图 + 局部状态贴片）**
   - **桌面待机 / 跳跃（`free_stand`）**：WebGL 实时带装网格站在圆形软木垫上呼吸、眨眼、摸头、点击桌面安全区连续蹦跳位移（含近大远小透视缩放与双层脚底阴影）。
   - **钻被窝睡觉（`sleep`）**：切入被窝贴片，当前穿戴的帽子与围巾自动摘在**木床顶框**与**右侧小圆边几**上。
   - **趴着画画（`drawing`）**：切入蜡笔涂鸦贴片，头饰单锚点挂载在头顶，点击画纸发光点可收下涂鸦心意。
   - **翻衣箱臭美（`dress_rummage`）**：桌面敞开迷你衣箱，点击直通试衣台。
   - **外出偶遇（`away`）**：空房留守 + 爪印字条 + 左下信封到信提醒。
2. **同场景推镜「专门试衣间」（`fitting`）**
   - 点击右下「去换装」圆钮或桌面「试衣镜」，镜头平滑推近 `1.44x` 聚焦软木垫试衣圆台。
   - 支持 **玉兔 / 锦鲤** 无缝切换，支持 **先试穿、后买单**（未解锁单品免费上身实时预览网格动态，确认穿出门时消耗陪伴星星 ⭐ 解锁）。
3. **零 Token 纯前端合成「带妆插画明信片」**
   - 无需生图 API Token，离屏渲染当前 `OutfitState` WebGL 姿态并叠入多套插画远景底图、脚底接触阴影与场景环境色柔光。
   - 点击「收下并贴上墙」后收入右下「纪念册」，并同步钉在起居室窗边墙面上。

## 本地运行与资源重建

```bash
# 重新生成场景与宠物裁剪贴图（仅改素材时需要）
python3 living-room-dress/prepare_scene_assets.py

# 在仓库根目录启动静态服务预览
python3 -m http.server 4173
# 访问 /living-room-dress/
```
