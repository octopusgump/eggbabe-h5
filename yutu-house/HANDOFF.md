## 4. 已实现功能（基线）

- 站立时呼吸起伏、间歇眨眼；走动时左右翻转、蹦跳步，到达后有落地回正。
- 点击地板任意可走位置，玉兔寻路走过去；点顶栏房间名会走到该房间目标点。
- 穿门：卧室与咖啡角、卧室与小厨房的隔墙上有门洞，寻路会绕障碍、穿门洞。
- 障碍：可行走多边形 + 家具/墙体障碍孔；点到不可走位置会打叉，并吸附到附近可行点。
- 遮挡：7 张从房间图切出的遮挡图层，按角色与物体基线比较前后关系（角色可走到桌、椅、墙前面或后面）。
- 光照：按位置从背景取样，给角色做 multiply 染色，减少「贴纸感」。
- 相机：默认约 0.55 倍；拖拽平移；滚轮或双指缩放，范围 0.45–1.5；走动时镜头跟随，手动拖/缩放后约 2.5 秒恢复跟随。
- 点击涟漪、房间切换时的名称 toast、四房间顶栏芯片高亮。

## 5. 技术架构（重要）

这不是完整真 3D 场景。

- 世界是一张 864×1152 的小屋俯斜构图（CG 袖珍小摆件风，整栋房子在苔藓草地小岛上）。
- 角色是正面 / 闭眼 / 侧面三张 WebP 精灵，画在 canvas 上做翻转、呼吸和染色。
- 寻路、门洞、遮挡都是 2D：可行走多边形、障碍多边形、手工切的遮挡图。
- 隔墙做成矮墙切面，是为了四间房一眼看全；门是墙上的缺口，不是独立 3D 门模型。

四间房连成一栋小房子，布局（俯视）：后排左咖啡角、后排中卧室、后排右小厨房，前排阳光房。

舞台：390×844 竖屏适配容器。

## 6. 如何从源文件重建（仅在需要改资源时）

在 `src/` 目录执行：

```bash
python3 mkgeom.py      # 写出 geom.json（外轮廓、障碍、房间、遮挡多边形）
python3 prep.py        # 依赖 Pillow、numpy；从 house.jpg 切 occ0–occ6.webp，并写出带光照表的 geom_full.json
python3 build.py       # 把 WebP 与几何嵌入 template.html，写出 ../yutu_house_demo.html
```

`build.py` 会嵌入：`house.webp`、`house_s.webp`（模糊边）、`front.webp` / `closed.webp` / `side.webp`、`occ0.webp`–`occ6.webp`、`geom_full.json`。

辅助脚本（不是日常重建所必需）：

- `ov.py` / `g3.py` / `grid.py` / `zc.py` / `probe.js`：标几何、量坐标用的调试工具
- `cap.js`：用 Puppeteer 按时间轴截帧做预览；脚本里仍写着原来的 `/workspace/yutu_demo/...` 路径，在本机要改路径和 Chrome/Puppeteer 位置后才能用

角色精灵来自既有玉兔素材（正面/闭眼来自 v2b 贴图，侧面来自四视图），本包已包含实际使用的三张 WebP，无需再取仓库文件。

`src/house.jpg` 与历史上的 `yutu_house_world.jpg` 内容相同，只保留前者。
