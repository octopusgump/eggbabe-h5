# 窗口命名：模型 | 项目 · 内容

## 为什么要这样起名

老板同时开着五六个窗口：一个总管在派活，几个在写代码，几个在审核。他不看代码、不记分支名，
只看会话列表。如果窗口名是「T1」「session for PR #218」「Task: implement…」，他要点进去才知道谁在干嘛。
名字统一成「模型 | 内容」之后，一眼就能回答三个问题：这是谁在干（模型）、在干什么（内容）、
是干活的还是审核的（开头两个字）。

## 格式

```text
<模型> | <内容>                 一个项目只有一两个窗口时
<模型> | <项目> · <内容>        同一项目同时开着三个以上窗口时（2026-09-09 起）
```

- **模型**：写模型的短名，首字母大写：`Fable`、`Opus`、`Sonnet`、`Haiku`。不写版本号，不写 `claude-`。
- **竖线**：半角 `|`，两边各一个空格。
- **项目**：两到四个字的项目名，例如 `技术标`、`标书工作台`、`爬虫`。用半角中点 `·`，两边各一个空格。
  项目名只在**同一个项目同时开着三个以上窗口**时加——这时会话列表里会有一串「审核××」「修复××」，
  没有项目名就分不清哪个审核属于哪条线。只开一两个窗口时不加，名字越短越好。
  **一条线上的窗口要么都带项目名，要么都不带**，不要混。
- **内容**：**十个汉字以内**，说清这个窗口在处理的对象或动作。数字、英文缩写各算一个字；项目名和中点不计入这十个字。
  加了项目名后整行最长约十四个字，超了先砍内容里的修饰词，项目名不动。
- **审核窗口**以「审核」开头，**修复窗口**以「修复」开头，**总管**写「主窗口 · <项目或任务>」。其余写动作加对象，不用加"窗口""任务"这些词。

## 例子

| 场景 | ✅ 这样起 | ❌ 不要这样 |
|---|---|---|
| 总管窗口 | `Fable \| 主窗口 · 技术标` | `Claude Code Session`、`biaokankan main` |
| 同一项目多窗口·写代码 | `Opus \| 技术标 · 同步节 meta` | `Opus \| 母版改版同步项目节` |
| 同一项目多窗口·审核 | `Sonnet \| 技术标 · 审核插图库规范` | `Sonnet \| 审核插图库规范`（分不清属于哪条线） |
| 同一项目多窗口·跑批 | `Sonnet \| 技术标 · 许昌胖东来` | `Sonnet｜技术标全本｜许昌胖东来`（全角竖线、两段） |
| 写代码 | `Opus \| 移除旧预览链路` | `T1 移除 ONLYOFFICE 与 PNG 预览链路（Opus）` |
| 写代码 | `Sonnet \| 原文轻预览模块` | `feature/claude-tender-light-preview-render` |
| 页面 UI | `Sonnet \| 标书工作台页面` | `T3 标书填写工作台 UI 实现` |
| 审核 | `Sonnet \| 审核轻预览模块` | `Review PR #219` |
| 修复审核意见 | `Sonnet \| 修复轻预览定位` | `fix followup for review comments` |
| 设计工具 | `Sonnet \| Figma 补工作台` | `把六张板建进 Figma 文件` |
| 文档 | `Sonnet \| 补协作规则` | `docs update` |

判断内容够不够短：读出来像会话列表里的一行标签，而不是一句话。超过十个字先删修饰词
（「一下」「相关」「功能」「任务」），再删对象里可省的部分（「标书填写工作台页面」→「标书工作台页面」）。
带项目名时同理，只砍内容那一段，项目名保持原样，这样同一条线的窗口在列表里对齐、能一眼扫出来。

## 什么时候动手

1. **开新窗口时**：`create_session` 的 `title` 直接按格式写，不要先随便起再改。
2. **派子 agent 时**：Agent 工具的 `description` 也按同一格式写（去掉模型部分也可以，因为子 agent 的模型由参数决定），例如「审核抓取器改动」。
3. **接手一批旧窗口时**：先 `list_sessions` 看一遍，名字不合格式的用 `set_session_title` 逐个改掉，包括你自己这个窗口。改完告诉用户"窗口已按统一格式改名"，不用逐个念。
5. **同一项目第三个窗口开出来时**：给这条线上已有的窗口（含主窗口）补上项目名，让它们在列表里成一组。
4. **汇报时**：用窗口名称呼窗口，不用 T1、T2、PR 号代替。例如"「Sonnet | 审核轻预览修复」刚开，专门审 #223"。

## 别做过头

- 名字只管辨认，不承担进度。进度写在汇报表里，不要把「已完成」「进行中」塞进窗口名。
- 一个窗口只起一次名，中途任务没变就不改；任务真变了（同一窗口串行换了分支）再改。补项目名不算改任务，可以做。
- 不要为了凑十个字硬加信息，四五个字够清楚就四五个字。
